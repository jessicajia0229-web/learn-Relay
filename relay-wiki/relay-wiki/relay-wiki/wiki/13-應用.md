# 應用

**一句話**：從家裡的冰箱、路上的汽車，到工廠和電網，都有繼電器。[S3][S4][S5][S6]

| 領域 | 例子 | 來源 |
|---|---|---|
| 家電 | 冰箱、冷氣、洗衣機、微波爐（切換壓縮機、加熱元件、計時器） | [S3][S4][S5] |
| 汽車 | 頭燈、起動馬達、燃油泵、冷氣、門鎖 | [S4][S5][S6] |
| 工業自動化 | 控制面板、馬達、電磁閥、重型機械 | [S3][S4][S5] |
| 電力系統 | 偵測故障並觸發斷路器，保護變壓器、發電機、輸電線 | [S3][S4][S5] |
| 安全系統 | 急停按鈕、防護門、光幕、雙手操作裝置 | [S5][S6] |
| 警報與保全 | 偵測入侵時觸發警報、燈光、門鎖 | [S5][S6] |
| 電信 | 訊號切換、路由 | [S4][S5] |
| 照明與舞台 | 照明控制、燈光調光（SSR） | [S1][S5] |
| 創客專題 | Arduino 控制馬達、家電 | [S2] |

## 繼電器在系統中的位置
- 感測器（輸入）→ 控制器 → **繼電器（輸出／執行器）**[S1] → 負載
- 實例：Arduino → 電晶體 → 繼電器 → 馬達 [S2]
- （閉迴路控制、自保持電路屬進階內容，不納入）
