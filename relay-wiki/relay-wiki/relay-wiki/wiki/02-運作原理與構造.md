# 運作原理與構造（電磁繼電器 EMR）

**一句話**：線圈通電變成電磁鐵 → 吸動銜鐵 → 帶動接點切換；斷電後彈簧把它拉回原位。[S1][S3][S4][S5][S6]

> 本頁為 6 份資料中交叉驗證最充分的內容。

## 構造
| 零件 | 作用 |
|---|---|
| 線圈 | 通電後產生磁場，是唯一的動力來源 [S1][S4] |
| 鐵芯／軛鐵 | 軟鐵芯加強磁場；固定部分稱軛鐵（yoke）[S1][S4] |
| 銜鐵 | 可動的金屬片，被磁力吸動，把磁力轉成機械動作 [S1][S4] |
| 彈簧 | 斷電後讓銜鐵復位，也維持接點壓力 [S1][S4] |
| 接點 | 導電金屬片，負責開關外部電路 [S1][S4] |
| 框架 | 支撐所有零件 [S4] |
| 支點（pivot） | 銜鐵轉動的軸心 [S1-F2] |
| 氣隙（air gap） | 銜鐵與軛鐵之間的間隙，通電後被吸合 [S1-F2] |
| 推卡（card） | 把銜鐵的動作傳給接點 [S5-F1] |
| 線圈軸（spool） | 纏繞線圈的骨架 [S5-F1] |

> 圖：S1-F2（示意圖）、S5-F1（標示詳細的構造圖）、S3-P1（拆殼實拍）。見 [images.md](../images.md)。

## 運作三步驟 [S3]
1. **產生磁場**：電流流過線圈，產生磁力。[S3][S4]
2. **接點切換**：磁力吸動銜鐵，接點位置改變，電流開始流通或停止。[S3][S4]
3. **斷電復位**：線圈斷電，彈簧把銜鐵拉回，接點回到原狀態。[S1][S3][S5]

## 電磁鐵的重要性
- 磁場強度取決於**線圈電流**和**線圈匝數**。[S4]
- 沒有電磁鐵產生的力，銜鐵就不會動，整個開關動作無法開始。[S4]

## 兩個電路，靠磁場連在一起
- 繼電器裡有兩個電路：電路一是線圈（電磁鐵），電路二是帶彈簧的開關（接點），兩者靠磁場連動。[S6]

## 教學備註
- 〔推論〕可用「零件 → 動作」對照圖呈現，讓新手把 S3 的三步驟和 S1/S4 的零件名稱對起來。
- 〔圖片觀察〕彈簧不一定是螺旋狀：S3-P1 是**銅片彈簧**，S3-P2 是**螺旋彈簧**。可提醒新手對照實物時別找不到彈簧。
- 〔推論〕建議簡報把 S1-F2 示意圖與 S3-P1 實拍並排，逐一對應零件。
