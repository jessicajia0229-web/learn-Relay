# EMR 與 SSR 比較

**核心原因**：兩者的差別在於「**用什麼東西切換電路**」。EMR 靠電磁力推動**實體接點**；SSR 靠**半導體**導通或截止，沒有東西在動。[S5]
其他所有差異，都是從這一點延伸出來的。

| 比較項目 | 電磁繼電器 EMR | 固態繼電器 SSR |
|---|---|---|
| 切換方式 | 機械接點移動 [S1][S4][S5] | 半導體 [S1][S4][S5] |
| 隔離方式 | 磁場 [S1] | 光耦合器 [S1] |
| 速度 | 較慢 [S1][S4] | 快 [S1][S4][S5] |
| 壽命 | 接點會磨損 [S1][S4] | 長，沒有機械磨損 [S1][S4][S5] |
| 聲音 | 「喀」聲 [S2][S4] | 靜音 [S4][S5] |
| 電弧 | 有 [S1] | 沒有 [S1] |
| 維護 | 需要 [S4] | 少 [S4] |
| 導通壓降與發熱 | 很小，發熱少 [S1][S4] | 1–2 V，發熱多，需散熱 [S1][S4] |
| 關閉時 | 完全斷開 [S1] | 有微小漏電流 [S1] |
| 價格 | 較便宜 [S4][S5] | 較貴 [S1][S4] |

## 來源衝突
- [S3] 說繼電器「維護需求極低」，但 [S1][S4] 都說 EMR 接點會磨損、需要維護。**採用 [S1][S4]**（兩份對一份，且說明較具體）。

## 教學備註
